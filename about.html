Assignment Requirements Workflow

This page provides an overview of the steps followed to build this HTML assignment according to the course guidelines.

  1. Set up valid HTML5 structure with correct doctype and title.
  2. Add semantic elements including header, nav, main, and footer.
  3. Organize heading hierarchy starting with h1 followed by h2.
  4. Include internal navigation and an external reference link.
  5. Add an image with descriptive alt text inside the assets folder.
